# Spark 数据处理与分析项目集

本项目包含6个典型的Spark数据处理与分析案例，涵盖RDD操作、DataFrame SQL、机器学习建模、推荐系统等核心场景。

## 项目列表

### 1. 学生选课数据分析 (RDD)
**文件**: `data01.txt`, `A.txt`, `B.txt`  
**技术栈**:
- RDD转换操作(map/filter/reduceByKey)
- 数据聚合(distinct/count/sum)
- 多文件合并(union)
- 分组统计(groupBy)

**功能**：
- 学生人数统计
- 课程数量统计
- Tom的平均分计算
- 选修课程数统计
- 数据库课程选修人数
- 课程平均分计算
- 多文件合并去重

**亮点**：
- 完整展示RDD核心操作链
- 多数据源合并处理
- 分组聚合统计实现

---

### 2. JSON数据SQL分析
**文件**: `data03.txt`  
**技术栈**:
- Spark SQL
- JSON解析
- JDBC数据库连接
- SQL语法全集

**功能**：
- 数据去重
- 字段筛选
- 条件过滤(age>30)
- 分组聚合
- 排序操作
- 别名设置
- 聚合函数(min/avg)
- 全量数据写入MySQL

**亮点**：
- 完整SQL语法演示
- 结构化数据读写
- 数据库集成示例

---

### 3. 泰坦尼克生存预测 (ML)
**文件**: `titanic.csv`  
**技术栈**:
- Spark ML Pipeline
- 特征工程(StringIndexer/OneHotEncoder)
- 逻辑回归模型
- 模型评估(BinaryClassificationEvaluator)

**流程**：
1. 数据清洗(去空值)
2. 类别特征编码
3. 特征向量化
4. 训练测试集划分
5. 模型训练与预测
6. AUC评估

**亮点**：
- 完整机器学习流程
- 特征工程最佳实践
- 分类模型评估方法

---

### 4. 电影推荐系统 (ALS)

- 显式反馈模型训练
- 隐式反馈模型训练

**亮点**：
- 推荐系统经典实现

## 技术全景图
| 技术领域       | 覆盖点                                  |
|----------------|---------------------------------------|
| **核心开发**    | RDD/DataFrame API、数据清洗、SQL语法   |
| **机器学习**    | 特征工程、逻辑回归、模型评估           |
| **推荐系统**    | ALS算法、显式/隐式反馈、矩阵分解       |
| **数据管道**    | 多数据源集成、数据库读写、JSON处理     |
| **性能优化**    | 分区策略、缓存机制、并行计算           |
